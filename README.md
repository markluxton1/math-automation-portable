# Math Automation Portable

Minimal filesystem-backed research machine reconstructed from the preserved v0.4 and
`distributed_experiment` substrate. It has no canonical mathematical outlook, no model
provider integration, and no swarm orchestration.

Run `python3 -m math_automation.cli --help` or `python3 -m unittest discover -s tests -v`.

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and [docs/MIGRATION.md](docs/MIGRATION.md).
